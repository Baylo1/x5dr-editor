## Overview

The X5DR has 430 Multisound entries (000–429), used as the sound source for OSC1 and OSC2 in Program Edit. Entries marked with **(P)** include stereo panning. Numbers 318–325 are VS (Vector Synthesis) waveforms.

## Notes

- **(P)** — Stereo pan version (indicated in manual with circled P symbol).
- Numbers **318–325** are VS (Vector Synthesis) waveforms (VS 102, VS 48, VS 52, VS 58, VS 71, VS 72, VS 88, VS 89).
- Number **326** (`13 – 35`) is a range descriptor, not a name error — preserved as printed in the manual.
- These numbers correspond to values selectable for OSC1 Multisound and OSC2 Multisound in Program Edit (TABLE 1, parameters at addresses 00–01 and 05–06 as cross-referenced in TABLE 7).
