## Overview

The X5DR has 215 Drum Sound entries (000–214), used in Drums Edit for per-note sound assignment. These map to the drum kit note parameters in TABLE 6 (Drums Parameter Table) and the Drum Kit Parameter Change format (Func=53).

## Notes

- These sound numbers correspond to the **Drum Sound** selection parameter in Drums Edit (TABLE 6).
- The Drum Kit Parameter Change function code is `53` (as distinct from the general Parameter Change `41`).
- Entry **088** is labeled `R – Timbal` in the manual (the dash appears to indicate "Rim" — preserved as printed).
- Entries **181–188** (BISS, BOOFN, BOOGETA, CHLACK, COOSH, COUGH, ISSH, POOM) are onomatopoeic percussion sound names, preserved exactly as printed.
